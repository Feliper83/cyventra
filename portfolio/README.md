## 🎯 HOW TO USE

### For PDF/Portfolio Document
1. Open `CYVENTRA_PORTFOLIO_EN.md` or `CYVENTRA_PORTFOLIO_ES.md`
2. Copy the content
3. Convert to PDF using:
   - **Markdown to PDF tools** (e.g., Pandoc, Markdown PDF)
   - **Online converters** (e.g., Dillinger, Markdown to PDF)
   - **VS Code extensions** (e.g., Markdown PDF)
   - **Google Docs** (paste and format)

### For LinkedIn
1. Open `LINKEDIN_POST_EN.md` or `LINKEDIN_POST_ES.md`
2. Copy the content (excluding the title)
3. Paste directly into LinkedIn post editor
4. Add relevant hashtags if needed
5. Include images if available (company logo, team photos, etc.)

### For Email

**Plain Text Version:**
1. Open `EMAIL_TEMPLATE_EN.md` or `EMAIL_TEMPLATE_ES.md`
2. Customize:
   - Replace `[Name]` with recipient's name
   - Replace `[Your Name]` with your name
   - Add calendar link if available
   - Adjust content as needed
3. Copy and paste into your email client

**HTML Version (Professional):**
1. Open `EMAIL_HTML_EN.html` or `EMAIL_HTML_ES.html`
2. Customize:
   - Replace `[Name]` with recipient's name
   - Replace `[Your Name]` with your name
   - Add calendar link if available
   - Adjust content as needed
3. Open in browser and copy the rendered HTML
4. Paste into your email client (Gmail, Outlook, etc.) or use as HTML source

### For One-Pagers
1. Open `CYVENTRA_ONEPAGER_EN.md` or `CYVENTRA_ONEPAGER_ES.md`
2. Convert to PDF using the same methods as the full portfolio
3. Use for:
   - Quick introductions
   - Leave-behind materials
   - Email attachments
   - Conference handouts

### For Pitch Deck
1. Open `PITCH_DECK_OUTLINE.md`
2. Use as a guide to create slides in:
   - PowerPoint
   - Google Slides
   - Keynote
   - Canva
3. Customize content based on your audience (investors vs. clients)
4. Add visuals, charts, and company branding

## ✨ CUSTOMIZATION TIPS

### Before Sending/Posting:
- ✅ Update statistics if numbers have changed
- ✅ Add specific project examples if available
- ✅ Include client testimonials if you have them
- ✅ Add your LinkedIn profile URL
- ✅ Include your calendar booking link
- ✅ Add company logo/images where appropriate

### For Different Audiences:
- **Enterprise Clients**: Emphasize compliance, security, scalability
- **Startups**: Focus on speed, cost savings, flexibility
- **Tech Companies**: Highlight technical stack and expertise
- **Non-Tech Companies**: Simplify technical jargon, focus on business outcomes
